# PRESS2DIE — асимметричный хоррор (1 vs все)

Проклятая игровая приставка 90-х, внутри которой заперты люди. Один игрок — Палач, остальные (до 6) — выжившие, которые пытаются вырваться из картриджа.

## Установка

| Файл | Куда положить | Тип |
|---|---|---|
| `GameServer.server.lua` | `ServerScriptService` | **Script** |
| `GameClient.client.lua` | `StarterPlayer > StarterPlayerScripts` | **LocalScript** |

Всё (лобби, сцена выбора, 4 карты, интерфейс) строится кодом — ассеты загружать не нужно. Для теста в одиночку поставь `CONFIG.MIN_PLAYERS = 1` в начале серверного скрипта. Проверять удобнее в режиме **Test → Start (2–3 игрока)** в Studio.

Скрипты работают и с включённым `Workspace.StreamingEnabled`: лобби, сцена и жетоны с выходами помечены как Persistent, а перед телепортом место заранее подгружается.

## Цикл игры

1. **Лобби внутри приставки.** Это материнская плата с чипами и радиатором. Сверху вставлен картридж, на стене большой экран статуса. Встань на платформу перед одним из 4 картриджей, чтобы проголосовать за уровень.
2. **Сцена выбора.** На сцене 6 подиумов P1–P6 с прожекторами. Выжившие выходят на сцену слева направо в том порядке, в котором выбирали героя, и прожектор над их местом загорается. Под сценой — таблица из 6 картриджей-героев. У Палача своя таблица из 3 обликов. Когда Палач выбрал облик, сверху на тросах опускается монитор, на котором крутится его анимированная модель.
3. **Матч.** Чтобы открыть выход раньше, нужно собрать золотые жетоны (2 за каждого выжившего, но не больше 12). Если жетонов не хватило, выход откроется сам за минуту до конца. Открывается **один** случайный выход, к нему ведёт зелёный столб света. Каждое убийство добавляет Палачу 20 секунд.
4. **Итоги.** Экран GAME OVER / YOU ESCAPED / CONTINUE? / NO SIGNAL со статусом и числом жетонов каждого игрока. Погибшие и сбежавшие могут наблюдать за живыми.

## Карты (картриджи)

- **Холмы радости.** Проклятый уровень платформера: шахматные плато с пандусами, мёртвые петли, гигантские кольца, тотемы, финишные таблички «GOAL».
- **Аркада «Полночь».** Ночной зал игровых автоматов: ряды автоматов с проходами для погонь, автоматы с игрушками, танцевальный автомат, стойка призов, служебные комнаты.
- **Лабиринт 8-бит.** Неоновый лабиринт 13×13 со статуями-призраками и логовом Палача в центре. **Стены перестраиваются каждый матч.**
- **Детская 1996.** Выжившие крошечные, мебель гигантская: можно спрятаться под кроватью и под столом. На полу ковёр-автотрек, рядом ЭЛТ-телевизор и сама приставка PRESS2DIE. Выходы — щель под дверью, мышиная нора и вентиляция.

## Персонажи

| Выжившие | Здоровье / скорость / выносливость |
|---|---|
| Алекс — школьник | 3 / 3 / 3 |
| Оскар — мастер по ремонту | 5 / 2 / 3 |
| Лилиан — спидраннерша | 2 / 4 / 4 |
| Грег — продавец картриджей | 4 / 3 / 2 |
| Айша — чемпионка аркад | 2 / 5 / 3 |
| Феликс — бета-тестер | 3 / 3 / 4 |

| Палачи | Способность (Q) |
|---|---|
| Палач — хозяин картриджа | **Рывок**: мгновенный рывок вперёд |
| Сбой — ошибка в коде | **Помехи**: 5 с видит всех выживших сквозь стены, у них экран идёт помехами |
| Бинки — талисман приставки | **Прятки**: 6 с невидимости, удар раскрывает |

У каждого героя своё снаряжение на модели (кепка, каска, наушники, телевизор вместо головы, уши маскота…) и такой же плоский портрет в интерфейсе.

## Интерфейс

- **Список игроков (слева сверху).** Портрет в наклонной рамке из изоленты, имя, зелёная полоса здоровья со счётчиком `x100` и тонкая полоса выносливости. Палач обведён красной концентрической рамкой опасности.
- **Свой HUD (слева снизу).** Анимированная 3D-модель своего героя повторяет стойку, шаг и бег и вздрагивает от удара. Под ней жёлтый счётчик `xHP`, широкая полоса здоровья в цвете героя с красным «лезвием» и сиреневая полоса выносливости `xST`.
- **Часы-таймер (сверху).** Выдержаны в том же стиле: наклонная рамка, изолента по углам, пиксельное табло. За минуту до конца появляется красная рамка тревоги, в последние 10 секунд часы трясутся, за каждое убийство циферблат вспыхивает красным.
- **Экранные эффекты.** ЭЛТ-выключение и включение экрана между этапами, сканлайны, помехи. Заставка уровня в стиле 16-битных игр. Освещение подстраивается под зону, где находится камера.

## Управление

| Действие | Клавиатура | Геймпад | Телефон |
|---|---|---|---|
| Бег | Shift | L3 | кнопка RUN |
| Способность Палача | Q | Y | кнопка EXE |
| Выбор героя | ← → / A D, Пробел | D-pad, A | тап по картриджу, тап ещё раз |
| Наблюдение | ← → | D-pad | кнопки < > |

Все числа (время, урон, скорость, жетоны, кулдауны) собраны в таблице `CONFIG` в начале серверного скрипта.
